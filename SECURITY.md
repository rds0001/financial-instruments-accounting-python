# Security

Report reproducible security issues privately to riskdatascience@web.de.
This local reference library does not start servers, send telemetry or fetch updates.
Treat external workbooks as untrusted input. The reader does not evaluate formulas;
canonical numeric validation rejects formula strings. Excel exports escape strings
beginning with =, +, - or @. No passwords or account credentials are required.
Do not put confidential records in issue reports or distribute them as examples.
